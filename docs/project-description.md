This project was created as a practical assignment to learn and demonstrate the fundamentals of Git and GitHub. It is a simple Python-based calculator that performs basic arithmetic operations.

Through this project, I practiced:

- Initializing a local Git repository
- Creating a proper project folder structure
- Working with branches (`feature/calculator` and `feature/error-handling`)
- Making multiple commits with clear messages
- Merging branches
- Connecting local repository with GitHub and pushing code
- Using `.gitignore` to keep the repository clean

### Features

- Add, Subtract, Multiply, and Divide functions
- Basic error handling (e.g., divide by zero)
- Clean and organized code structure
