## Project Description

This project is a simple Python calculator developed as part of the Git and GitHub learning assignment. The main purpose was to practice real-world version control workflows using Git and GitHub.

I created this repository from scratch, set up the proper folder structure, worked with multiple branches, made several commits, and successfully pushed everything to GitHub.

### Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication, and Division
- Basic error handling (e.g., preventing division by zero)
- Clean and organized project structure
- Proper use of Git branching and merging

### What I Practiced

- Initializing a Git repository
- Creating and managing branches (`feature/calculator` and `feature/advanced-calculator`)
- Making meaningful commits
- Merging branches into `main`
- Using `.gitignore`
- Connecting local repository with GitHub
- Maintaining proper folder structure

### How to Run

python src/main.py
